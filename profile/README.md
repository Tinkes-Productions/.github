# Tinkes Productions

Games and mods by Rasmus (Tinkes) from Finland. I'm studying software development at Valkeakosken ammattiopisto alongside upper secondary school, and this is where my own projects go. Most of them are still in development and stay private until they're playable.

## Projects

**Thief Coop** · *in development*
A co-op mod for Thief Simulator 1, made with Sinerla Development. The name is a chicken coop joke. The release and a trailer come once it's been properly playtested.

## Tools

- **Games** Unity, Godot, Unreal Engine, Pygame
- **Code** C#, Python, JavaScript, Node.js / Express, HTML & CSS
- **Other** OpenCV, Raspberry Pi, ffmpeg, Git

I draw my own 2D art. I don't do 3D modeling, so my games are mostly 2D.

## Sinerla Development

Some projects are made together with [Sinerla Development](https://github.com/Sinerla-Development), who focus on automation, IoT and audio engineering.
